    Experiment studio

    Write an experiment as a JavaScript function of its parameters, test-run it live, then publish. Visitors get sliders and a Run button.

    Script reference (what you can use) 
    // Your script receives  params  (the slider values)  and  Lab  (helpers). It must  return  a result:
return {
  charts: [{ title, xLabel, yLabel, logY: false,
             series: [{ name, x: [...], y: [...], style: "line" | "points" | "bars" }] }],
  metrics: { speed: { label: "Top speed", value: 12.3, unit: "m/s" } },   // or  speed: 12.3
  table: { columns: ["a","b"], rows: [[1,2],[3,4]] },                     // optional
  notes: "Shown under the results"                                         // optional
};
Lab.constants   g, c, G, kB, NA, R, h, e                Lab.rng(seed) -> () => 0..1   Lab.normal(rng, mean, sd)
Lab.sum  mean  std  min  max  round(v, digits)           Lab.linspace(a,b,n)   Lab.range(a,b,step)   Lab.column(rows, i)
Lab.binomial(rng, n, p)   Lab.linreg(xs, ys) -> {slope, intercept, r2}

        Scientist Tutorial

        Build a lab, script an experiment, write it up and publish.

        1. Start with the starter pack

        1. On the Dashboard press Import starter pack. Open an experiment from the list to see how a script is written, change numbers and press Run test.

        2. Create a lab

        1. Open Labs and add a themed room (Physics, Chemistry, Biology …) with an emoji and colour.

        3. Script an experiment

        1. In Experiment studio pick a lab, add parameters (each becomes a slider for visitors) and write the script. It receives params and Lab, and returns charts, metrics and an optional table.
        2. Give metrics short keys (e.g. range). A goal such as “range at least 120” turns the experiment into a challenge with a badge.
        3. Press Run test as often as you like. Errors show the message and line. Scripts that run longer than 5 seconds are stopped.

        4. Write a paper

        1. In Papers write an abstract and body, then link an experiment with chosen parameter values: readers can press Reproduce figure to run it themselves.

        5. Publish

        1. Open Publish, press Test-run every experiment, fix any red items and publish. You can restore any earlier version from the history.

        Good to know

        • Published scripts are public. Never put secrets in them.
        • Visitors run your script in their own browser, inside a sandbox with no network or storage access.
        Drafts stay in this browser until you publish. Publishing needs a Labs employee account.
