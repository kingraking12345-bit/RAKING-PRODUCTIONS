      Employee tutorial: create or edit a Games tab

      Create a tab

      1. Enter the page name and optional subtitle in the form below.
      2. In Tab code, the index.html, styles.css and script.js files are ready for you. Write your page in them. Use NEW SCRIPT to add more files: pick a script type, enter a file name, and choose Create file. Folders work the same way.
      3. Line numbers update as you type, and drafts autosave in this browser.
      4. Choose Add tab to Games preview. Your HTML, CSS, and JavaScript are applied to the tab automatically, and the tab is listed under Tabs in this browser.

      Edit a tab

      1. Find it under Tabs in this browser and choose Edit.
      2. Its saved HTML, CSS, and JavaScript load into Tab code. Make changes, then choose Save tab.

      Other files and folders can be organized and exported from the script manager. This preview saves to this browser only; it does not publish changes to GitHub or update other visitors' copies of the site.
