    Tools Employee Tutorial

    Create the AI, build tools, publish to everyone.

    Create the AI (Kignity AI)

    1. Open Kignity AI. The project KIGNITY AI already has a starter set: kignity.json (name, greeting, suggestions), skill scripts in skills/ and answers in knowledge/faq.json.
    2. Create folders and files the same way as for a tool: enter a name, choose the script type, press Create file. .js files run as AI scripts; .json, .md and .txt files are knowledge you read with Kignity.data("path"). Other languages are stored and exported but not run.
    3. A skill looks like Kignity.skill({ name, patterns, reply }). Open README.md in the project for every helper.
    4. Every edit reloads the AI. Talk to it in the Test chat; console.log output and errors show in the Script console. A script that runs longer than 2 seconds is stopped.
    5. When you are happy, open Publish and publish. Visitors then talk to your version of Kignity AI on the Tools page.

    Create a tool

    1. Press ＋ Create new tool (on the Kignity AI or Tools tab), enter a tool name, optional description and Refane price (0 = free).
    2. Choose Code. The project starts at NEW TOOL with index.html, styles.css and script.js. Create more folders and files beside the editor; select a folder first to nest a file in it.
    3. Use Preview tool to test in a restricted sandbox. HTML, CSS and JavaScript run; other languages are stored and exported only.
    4. Press Save draft, then Publish in the tool list to mark it ready, and finally publish to everyone from the Publish tab.

    Tease the next tool

    1. Open Tool announcements, add the tool name, banner, subtitle, description, and release date.
    2. Press Publish on the teaser, then publish to everyone from the Publish tab. It appears in the Tools Library announcement list.
    Drafts stay in this browser until you publish. Publishing needs a Tools employee account.
